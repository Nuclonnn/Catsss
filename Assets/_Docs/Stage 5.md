Цель: Создать универсальные компоненты с настройками в инспекторе. Все пазлы на уровне будут собираться только из этих 4-х префабов.
Задача 5.1: Магические Печати (Универсальные Кнопки)
•	Создай скрипт MagicSeal.
•	Настройки (Enum): Standard (инпут "E"), HeavyWeight (нужен заряд isHeavy), Impact (нужен удар в состоянии DashState).
•	Сетевая логика: Валидация нажатия происходит на Сервере. При успехе Сервер вызывает событие (через UnityEvent в инспекторе и/или глобальный SO EventChannel).
•	Визуал: При активации Печать локально меняет материал на "светящийся".
Задача 5.2: Кинематические Платформы (Летающие Гримуары)
•	Создай префаб с NetworkObject и NetworkTransform (двигается только Сервером, интерполяция включена).
•	Настройки движения: Публичный метод PlayForward() и PlayReverse(). Логика перемещения между двумя Transform точками (или по Spline).
•	Настройки Активации (Enum):
o	SignalDriven: Ждет вызова PlayForward() извне (от Печати).
o	Resonance: Имеет триггер на крыше. Если на него встает игрок с определенным chargeID — платформа едет. Спрыгнул (или заряд кончился) — едет обратно.
Задача 5.3: Антимагические Зоны (Барьеры)
•	Создай префаб с прозрачным BoxCollider (IsTrigger).
•	Сетевая логика (Сервер): При OnTriggerEnter, если это игрок с зарядом -> Сервер обнуляет его заряд и применяет штраф (Телепорт на respawnPoint Источника, как в Этапе 3). Обычных игроков барьер игнорирует.
•	Настройка в Инспекторе: Галочка BlocksProjectiles.
o	Если true — летящий заряд (из Этапа 4) при касании уничтожается ("пшик").
o	Если false — снаряд пролетает насквозь. Это позволит собирать пазлы, где игроки перекидывают искру сквозь барьер.
Задача 5.4: Аэродинамика (Потоки ветра)
•	Важно: Так как передвижение игроков Client-Auth, ветер должен влиять на локального PlayerController игрока (без ожидания ответа сервера).
•	Создай скрипт AeroZone с триггером.
•	Логика на Клиенте (OnTriggerStay):
o	Если игрок в HeavyState (Тяжелый) -> Игнорировать ветер (AddForce = 0).
o	Если игрок в AirState (Воздушный) -> Применить огромный импульс вверх (работает как батут).
o	В обычном состоянии -> Применять мягкий сдвиг в заданном направлении (AddForce).
